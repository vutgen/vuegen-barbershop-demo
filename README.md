# BLACKLINE — демо-макет сайта барбершопа

Демонстрационный проект студии vuegen: тёмная тема, цены, мастера, галерея, онлайн-запись (заявка в WhatsApp).
Название, адрес, имена мастеров и телефон вымышлены. Фото: Unsplash (бесплатная лицензия Unsplash).
Сделан из шаблона `shablon/barber`: весь контент в `config.js`.
