# BlackLine — демо-макет сайта барбершопа

**Смотреть:** https://vutgen.github.io/vuegen-barbershop-demo/

Демонстрационный проект студии vuegen: тёмная тема, цены, мастера, галерея стрижек, онлайн-запись со свободными часами (заявка уходит в WhatsApp), адаптация под телефон.

- Название, адрес, телефон и имена мастеров вымышлены.
- Фото с Unsplash (бесплатная лицензия Unsplash).
- Обычный HTML/CSS/JavaScript, без конструкторов и сборки. Весь контент (тексты, цены, фото, цвета) лежит в одном файле `config.js`, поэтому под другой бизнес сайт переделывается быстро.
